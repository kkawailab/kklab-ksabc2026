河合担当分講義一覧（第6〜10回）

  1. Lecture0611/2（月）

    経営情報の基礎：企業（組織）とソーシャルメディア

    経営情報の基本概念（データ・情報・知識と意思決定）と、ソーシャルメディアが企業と顧客・組織内の関係をどう変えたかを学ぶ。

     講義ページ →
  2. Lecture0711/9（月）

    人工知能：企業における生成AI

    AIの発展と生成AI（大規模言語モデル）のしくみを概観し、企業での活用、限界・リスク、AIガバナンスを学ぶ。

     講義ページ →
  3. Lecture0811/16（月）

    つながり：ネットワークがもたらす企業の変化

    ネットワーク効果、プラットフォームと両面市場、ネットワーク科学の基本概念を通じて、「つながり」が企業の競争と価値創造をどう変えたかを学ぶ。

     講義ページ →
  4. Lecture0911/23（月）

    XテックとDX：企業のデジタル戦略

    Xテックの広がりとDX（デジタルトランスフォーメーション）の考え方を軸に、企業のデジタル戦略と、それを進めるうえでの技術・組織の課題を学ぶ。

     講義ページ →
  5. Lecture1011/30（月）

    あたらしい社会像：Society 5.0 と スマートシティ

    Society 5.0 の構想とそれを支える技術、スマートシティの取り組みと課題を通じて、企業の情報活用を社会の視点から位置づける。河合担当分のまとめと小テスト。
