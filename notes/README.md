## 組み立て

- 各ページは、トピックの導入、小見出しごとの本文、表または囲み、「確認」の問いの順です。「確認」は講義ページの「復習のポイント」とワークシートの問いに対応させています。
- 用語の説明は、ワークシートの「この回の用語」と同じ言い方にしています。
- 数値や定義は、講義アンケート（`assets/js/survey-data.js`）の事実欄で出典を確認済みのものを中心に使い、各ページの末尾に出典を記しています。配布の前に、新しい統計が出ていないか確かめてください。

## 配布のしかた

講義ノートは Teams に掲載します（講義サイトには載せません）。このフォルダをリポジトリに入れると、サイトの URL から誰でも取得できる状態になります。講義ページからはリンクしていません。

## 原稿を直すとき

原稿は `markdown/noteNN.md` です（`tex/` は生成物なので、直すのは Markdown のほうです）。直したら、次のコマンドで LaTeX、PDF、Word を作り直します。Python の `python-docx`、LuaLaTeX（`jlreq`、`tcolorbox`）、poppler-utils、LibreOffice が必要です。

```bash
python3 notes/build.py        # 5回分すべて
python3 notes/build.py 08     # 第8回だけ
```

ビルドは、トピック名が講義ページの「講義の流れ」と同じであること、各トピックが1ページに収まっていることを確かめ、収まらなければ、あふれたトピックを示して止まります。Word 版は LibreOffice で PDF にして同じ検査をしますが、Word 本体とはフォントが違うので目安です。各ページの使用率を表示するので、85% を超えるページは Word で開いたときにあふれる可能性があります。解釈する書き方は `build.py` の冒頭にまとめてあります。
