## 組み立て

- 各回は、ねらい、最近の話題、物語、この回の用語、演習、つづく（第10回は結末）、Teams への投稿の順です。
- 物語は5回で1つの話です。和菓子店「こもれび堂」を、学生が診断チームの一員として5週間かけて診ます。店、サービス、登場人物はすべて架空で、各回にその旨を記しています。
- 各回の要点は、物語の中で「診断カルテ」として書きとめます。第10回の問5で、5回分を振り返ります。
- 問1と問2は、話題、物語、この回の用語を読めば答えられる仕分け、穴埋め、短文です。
- 問3以降は、各講義ページの「考えてみよう（Teams投稿のテーマ）」の手順をそのまま問にしたものです。ワークシートの回答を投稿すれば、その回の Teams 投稿になります。第10回の問5だけは、5回をつなぐ振り返りとして加えた問です。
- 各問に書き出しを付け、問3にはソラのメモとして短い例を載せています。ワークシートに模範解答は付けていません。

## 原稿を直すとき

原稿は `markdown/worksheetNN.md` です。直したら、次のコマンドで Word と PDF を作り直します。Python の `python-docx` と、LuaLaTeX（`jlreq`、`tcolorbox`）が必要です。

```bash
python3 worksheets/build.py        # 5回分すべて
python3 worksheets/build.py 08     # 第8回だけ
```

解釈する書き方は `build.py` の冒頭にまとめてあります。問の見出しの「（目安：…）」を変えたときは、演習の冒頭の表と合計も合わせて直します。

## 教員用（模範解答入り）

`teacher/worksheets_teacher.pdf` は、全5回の回答欄に模範解答を記入し、1冊にまとめた教員用の PDF です。模範解答の原稿は `teacher/answers.md` です。ワークシートの本文を直したときは、作り直します。

```bash
python3 worksheets/build_teacher.py
```

このリポジトリは公開で、`main` に push すると内容がそのままサイトに載ります。そのため `teacher/` は `.gitignore` で Git の管理外にしています。コミットせず、Teams にも載せないでください。Git には残らないので、控えは別に取ってください。
